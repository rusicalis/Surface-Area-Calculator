# S.A.C Surface Area & Replenishment Calculator V1.0.14

## 변경 사항
- 최상단에 `표면적 계산` / `보충량 계산` 탭 추가
- 기존 V1.0.12 표면적 다중항목, 음수 차감, 수량 placeholder=1 기능 유지
- 보충량 계산: 탱크 용량 직접 입력 또는 가로×세로×액높이(mm) 자동 용량 계산
- 현재농도 > 목표농도: 폐수량 및 순수 보충량 자동 계산
- 현재농도 < 목표농도: 고형약품 또는 액상약품 보충량 자동 계산
- 고형약품: 순도(%) 반영, 빈칸은 100%
- 액상약품: 원액 g/L 입력 또는 wt% + 비중 입력 지원
- 액상약품: 정용량 유지 / 용량 증가 허용 방식 지원
- 액상약품 보충량을 L와 kg로 동시 표시
- 탱크 바닥 치수가 있으면 폐수량을 배출 수위(mm)로 환산
- 상단 VERSION 1.0.14 / T.S.HWANG 유지


## V1.0.14
- 액상약품이 kg 단위로 입고될 때 비중을 이용해 L로 환산할 수 있는 기능을 추가했습니다.
- 액상약품 입고/투입 단위에서 L 기준 또는 kg 기준을 선택할 수 있습니다.
- kg 기준 선택 시 입력 중량(kg)과 환산 부피(L)를 동시에 표시합니다.
- 기존 목표농도 기준 약품 보충량 계산은 그대로 유지합니다.

- kg 기준 입력량은 환산된 L를 실제 투입 부피로 적용하여, 선택한 정용량/용량증가 방식에 따른 적용 배출량·최종용량·예상농도를 함께 표시합니다.
