# S.A.C Surface Area Calculator V1.0.7

- iPhone 홈 화면 아이콘: `icons/sac-icon-180-v104.png`
- Android 기본 아이콘: `icons/sac-icon-192-v104.png`, `icons/sac-icon-512-v104.png`
- Android maskable 아이콘: `icons/sac-icon-192-maskable-v104.png`, `icons/sac-icon-512-maskable-v104.png`
- `manifest.webmanifest`와 `sw.js`는 V1.0.7 캐시 갱신을 적용했습니다.

GitHub Pages에 이 폴더의 파일 전체를 저장소 루트에 덮어쓴 뒤 배포하십시오.
기존에 홈 화면 바로가기가 이미 설치되어 있다면, iOS/Android의 아이콘 캐시 때문에 기존 바로가기를 삭제하고 다시 추가하면 새 S.A.C 아이콘이 즉시 반영됩니다.


## V1.0.7 변경
- 프로그램 내부 상단 좌측 로고 박스 안에도 `S.A.C` 문구를 표시합니다.
- 홈 화면용 S.A.C 아이콘 설정은 기존 V1.0.7 아이콘 리소스를 그대로 유지합니다.


## V1.0.7 변경사항
- 하단 입력/출력/원주율 정보 카드 삭제
- 모든 표시명을 `S.A.C`로 통일
- 계산식 설명에서 `× 수량` 문구 제거(실제 수량 계산은 유지)
- AUTO CALC 아래 `VERSION V1.0.7` 표시
- iOS/Android 홈 화면 아이콘도 `S.A.C`로 갱신


## V1.0.7
