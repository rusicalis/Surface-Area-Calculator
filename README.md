# S.A.C Surface Area Calculator V1.0.12

## 변경 사항
- 수량 입력칸의 실제 기본값 1을 제거하여 빈칸 상태로 시작
- 수량 입력칸의 placeholder(배경 표시)는 1 유지
- 수량이 비어 있으면 계산에서는 자동으로 1로 처리
- + 버튼으로 새 항목 추가 시 수량칸은 빈칸으로 생성되고 배경에 1 표시
- 입력값 초기화 시 수량칸도 빈칸으로 복원되며 배경 1 유지
- 다른 수량을 입력할 때 기존 1을 지울 필요 없이 바로 입력 가능
- 기존 다중 항목 추가/삭제, 음수 항목 차감, 카드별 합계, 총 표면적, S.A.C UI/PWA 기능 유지


- 상단 VERSION 아래 필기체 서명 `T.S.HWANG` 추가 (AUTO CALC와 동일 글자 크기)
