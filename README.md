# Surface Area Calculator V1.0.2

Mobile-first surface area calculator styled from the A.C.P.T mobile UI system.

## Calculation

- Formula 01: `Diameter × 3.14 × Height × Quantity`
- Formula 02: `Radius × Radius × 3.14 × Quantity`
- Input: `mm`
- Output: `dm²`
- Conversion: `10,000 mm² = 1 dm²`
- Results update automatically on every input change.

## Standalone Core

All calculator CSS and JavaScript are embedded directly inside `index.html`.
The calculation and visual layout therefore work even when `index.html` is opened without loading separate CSS or JavaScript files.

## Home Screen

### iPhone / iPad
1. Host the folder with GitHub Pages.
2. Open the HTTPS address in Safari.
3. Tap Share.
4. Tap Add to Home Screen.

### Android
1. Host the folder with GitHub Pages.
2. Open the HTTPS address in Chrome.
3. Choose Add to Home screen or Install app.

## GitHub Pages

Upload the contents of this folder to the repository root and enable GitHub Pages from the branch root.
